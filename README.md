### 🚀 Highlighted Project: QuickBite

> **QuickBite** is a resilient, enterprise-grade food delivery backend engineered on microservices principles.

```
                  ┌──────────────────────┐
                  │    API Gateway       │
                  └──────────┬───────────┘
                             │
     ┌───────────────────────┼───────────────────────┐
     ▼                       ▼                       ▼
┌──────────────┐      ┌──────────────┐      ┌─────────────────┐
│ User Service │      │ Order Service│      │ Payment Service │
│ (JWT & Auth) │      │ (Life-cycle) │      │ (Razorpay SDK)  │
└──────────────┘      └──────────────┘      └─────────────────┘
     ▲                       ▲                       ▲
     └───────────────────────┴───────────────────────┘
                             ▼
              ┌─────────────────────────────┐
              │ Restaurant & Delivery Engine│
              └─────────────────────────────┘
```

- 💡 **Architecture**: Decoupled microservices with dedicated databases, REST communication, and centralized routing.
- 🛡️ **Reliability**: Thorough test-driven coverage with unit and integration tests across DTOs, controllers, and domain models.
- 💳 **Payments & Integrations**: Integrated with Razorpay Client SDK for frictionless payment processing and state tracking.

👉 **[Explore the QuickBite repository](https://github.com/UDAY1810/quickbite)**
